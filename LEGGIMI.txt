mantenendo le cartelle.

DUE AGGIORNAMENTI, NON UNO
--------------------------
Il Worker e il sito sono due cose separate e vanno allineate insieme: se ne
aggiorni solo una, browser e Worker si parlano in due lingue diverse.

  cd cloudflare
  wrangler deploy
  cd ..

  git add -A
  git commit -m "fix 524: streaming del Consulente"
  git push

Poi Ctrl+Shift+R sul sito.


VERIFICA
--------
  npm run test:all        55 + 17 + 8 + 22 = 102 test
  npx vite build

Sul sito: scheda Consulente, "Analizza le campagne". Dopo qualche secondo il
testo comincia a comparire con un cursore lampeggiante in coda, e sopra una
riga azzurra dice che sta scrivendo. Le azioni applicabili arrivano alla fine,
quando il blocco <actions> e' completo.


SE IL 524 DOVESSE RITORNARE
---------------------------
Non dovrebbe: con i byte che scorrono la connessione non resta mai ferma 100
secondi. Se succede lo stesso, abbassa in cloudflare/wrangler.toml:

  ANTHROPIC_MAX_TOKENS = "8000"

e rifai wrangler deploy.
